### Role description

Project Managers write reports, run meetings, plan projects, review drawings, use dashboards and communicate with clients. They multitask heavily, with many windows open and frequent screen sharing. They benefit most from screen space and good communication kit rather than raw processing power, and they do not run CAD or rendering software.
